# Apro and Manager Productivity UI

## Pages

- Banking page: `http://127.0.0.1:5173/`
- Manager productivity page: `http://127.0.0.1:5173/managers`

## What I Built

This project is a React frontend created from two supplied design references.

- Installed React and Vite for the project setup.
- Created a component-based `src` structure with reusable navigation and tag components.
- Built the Apro business banking page using HTML and CSS UI mockups for accounts, balances, cards, and treasury details.
- Built the Empowered Managers productivity page using HTML and CSS for the goals list, analytics chart, employee card, and turnover statistic.
- Added two separate routes so each reference has its own page .

## Project Structure

```text
src/
```
